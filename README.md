# BitacoraRuta

Proyecto Android educativo para uso en clases.

## Requisitos

- Android Studio instalado
- JDK compatible con el proyecto
- Conexión a internet para que Gradle descargue dependencias

## Cómo descargar el proyecto

Opción 1: Descargar ZIP desde GitHub

1. Entrar al repositorio.
2. Presionar el botón verde **Code**.
3. Seleccionar **Download ZIP**.
4. Descomprimir el archivo.
5. Abrir la carpeta del proyecto en Android Studio.

Opción 2: Clonar con Git

```bash
git clone https://github.com/Fena14/BitacoraRuta.git
